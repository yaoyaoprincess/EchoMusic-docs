# 🎵 播放与音质

### 播放失败，提示「暂时无法获取可用音源」 {#no-audio-source}

可依次尝试：

1. 确认是否为 VIP 会员；非 VIP 可先[领取 VIP](/faq/account#get-vip)，或使用 SD 音质试听
2. 开启「设置 → 播放体验 → **智能兼容模式**」
3. 关闭代理/加速服务，或在「设置 → 网络 → 全局网络代理」中选择「直接连接」并点击「应用」后重试
4. 确认软件为最新版本，可开启「设置 → 关于 → 检查预发布版本」获取测试版
5. 以上均无效时，在设置中导出日志发给群主定位问题

::: warning 注意
若歌曲本身无版权或已下架，则无法通过上述方法解决。
:::

### 无法播放歌曲 {#cannot-play}

1. 检查网络连接是否正常
2. 确认账号已正常登录
3. 尝试切换音质（部分音质可能需要 VIP）
4. 重启应用

### 怎么听「蝰蛇母带 / 蝰蛇超清 / 蝰蛇全景声」 {#viper-audio}

蝰蛇音质需要**酷狗 SVIP**（注意：酷狗 SVIP 与酷狗概念版 VIP 是两回事）。

已是 SVIP 的用户，在「设置 → 播放体验」中开启「**蝰蛇音质**」即可。

### 歌曲还没播完就自动切到下一首 {#auto-skip}

到「设置 → 播放体验」中调整「**歌曲过渡**」选项。各选项的含义详见[播放控制](/guide/playback)。

### 无法切换音质 {#quality-switch}

部分歌曲可能只提供特定音质：

- Hi-Res 和 SQ 需要 VIP 账号
- 老歌可能只有标准音质

### 播放卡顿或断断续续 {#stutter}

1. 降低音质（设置 → 音质 → 标准）
2. 检查网络连接稳定性和速度
3. 关闭其他占用网络的应用程序

### 歌词不同步 {#lyrics-sync}

1. 尝试切换歌词源（如果歌曲有多版本歌词）
2. 在歌词设置中调整歌词延迟
3. 部分歌曲可能没有精确的逐字歌词，会回退到 LRC 歌词
