# 🔄 更新与反馈

### 如何检查更新 {#check-update}

EchoMusic 启动时会自动检查更新，也可以手动检查：**设置 → 关于 → 检查更新**。

想第一时间体验新功能，可开启「设置 → 关于 → **检查预发布版本**」获取测试版更新。

### 自动更新失败 / 下载速度很慢 {#update-slow}

EchoMusic 的更新与插件市场资源均托管在 GitHub，网络不畅时会导致更新失败或下载缓慢：

1. 在「设置 → 网络 → **GitHub 加速地址**」中填入群公告提供的公益加速站地址
2. 保存后重新检测更新

### 提示 net::ERR_CONNECTION XXX {#err-connection}

此错误表示网络请求被拦截或无法直连 GitHub，可依次尝试：

1. 在「设置 → 网络 → **GitHub 加速地址**」中填入群公告提供的公益加速站地址后重试
2. 关闭代理/加速服务，或在「设置 → 网络 → 全局网络代理」中选择「直接连接」并点击「应用」
