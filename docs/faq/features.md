# 🔧 功能使用

### 可以下载音乐吗 {#download-music}

**不支持，且项目明确永不支持下载音乐功能。** EchoMusic 不会提供音乐文件下载，也不会在本地缓存音频文件。如有下载需求，请自行寻找其他途径。

### 怎么添加本地音乐 {#local-music}

在「在线插件」中安装「**简单本地音乐**」或「**本地音乐**」插件，即可播放本地音频文件。插件的安装与管理详见[插件使用](/guide/plugins/)。

### 怎么听酷狗曲库里没有的歌曲 / 版本 / 音质 {#cloud-drive}

曲库里没有的歌曲、指定版本或指定音质，可以通过**音乐云盘**解决：

1. **有多端同步需求**：使用「音乐云盘」上传自己的音频文件；自动匹配不准时，可用「**匹配上传**」手动匹配。配合「**云盘优先**」插件，可自动优先播放云盘文件，实现听指定版本/音质
2. **封面/歌词等元数据缺失**：可先用 MusicTag 等工具将元数据嵌入音频文件后再上传；较新版本的 EchoMusic 已支持自动读取音乐文件元数据，补全播放信息
3. **无多端同步需求**：直接使用本地音乐插件即可（见上一条）

### 听歌识曲无法使用 {#music-recognition}

- **麦克风模式**：确保已授予麦克风权限，环境不要太嘈杂
- **系统音频模式**：确保音频正在系统中播放

### 私人 FM 推荐不准确 {#personal-fm}

FM 的推荐基于你的听歌历史和反馈：

1. 多使用「喜欢」和「不喜欢」按钮
2. 需要一定的听歌积累，推荐才会越来越精准
3. 多听不同类型的歌曲，丰富推荐维度

### 收藏的歌曲不见了 {#favorites-lost}

1. 确认是否已登录正确的账号
2. 收藏数据保存在本地，更换设备不会同步
3. 如果清除了应用数据，收藏会丢失
