# 👤 账号与会员

### 使用 EchoMusic 需要付费吗 {#free}

**不需要。** EchoMusic 是完全免费的开源项目。如果你是通过付费渠道获得的，说明被骗了。

### 如何领取酷狗概念版 VIP {#get-vip}

- **官方途径**：在手机端酷狗概念版 APP 中手动签到领取，这是唯一稳定可靠的方式。
- 社区存在第三方自动签到工具（签到类插件、GitHub 自动签到脚本等），但均非 EchoMusic 官方提供，存在账号风险且随时可能失效，本站不收录具体教程，请自行评估后查阅群公告/群文件。

> **免责声明**：第三方工具收集自社区渠道，与 EchoMusic 项目无关。使用此类工具产生的任何账号问题，请自行承担。

### 没有 VIP 能听歌吗 {#listen-without-vip}

较新版本已支持无 VIP 基础听歌：

1. 非 VIP 账号可免费试听 **SD 音质**
2. 开启「设置 → 播放体验 → 音频播放失败时尝试 MV 音频」，可在音源获取失败时自动兜底

需要更高音质，请先解决 VIP 问题。

### VIP 领取失败或会员歌曲无法播放 {#vip-verify}

此类问题本质是账号需要重新验证，按以下步骤操作：

1. 在手机端酷狗概念版 APP 中退出登录
2. 在手机端重新登录
3. 在 EchoMusic 中退出登录，并清除应用数据
4. 在 EchoMusic 中通过手机端扫码/确认重新登录

### 创建歌单 / 收藏音乐失败 {#playlist-fail}

1. 用酷狗概念版 APP 重新扫码登录 EchoMusic
2. 确认登录的是**酷狗概念版账号**——酷狗账号和酷狗概念版账号是两套账号体系，需要区分

### 如何注销 / 切换账号 {#switch-account}

在「设置 → 账号」中选择退出登录，然后重新登录其他账号。

### 账号安全吗 {#account-safety}

- EchoMusic 直连酷狗官方服务器
- 账号数据不经过第三方
- 建议使用强密码保护账号安全
